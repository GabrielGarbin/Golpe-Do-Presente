# Logo do Bradesco

O cabeçalho usa `logo-bradesco.png` (logo branco com fundo transparente, para o fundo vermelho).
Para trocar, substitua este arquivo mantendo o nome. A altura no cabeçalho é ajustada pelo CSS
(`.brand-logo` em `css/app.css`). Se o arquivo não existir, aparece o nome "Bradesco" em texto.
